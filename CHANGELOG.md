# Changelog

All notable public changes to ChatPins are documented here.

## 1.1.0 — 2026-10

First public release.

### Included

- Saved ChatGPT conversations independent of native pins.
- Browser side-panel interface.
- Color-coded folders.
- Search across titles, notes, and folders.
- Custom chat titles and notes.
- Manual drag-and-drop sorting.
- Sorting by title and last opened time.
- Quick removal from the saved list without deleting the ChatGPT conversation.
- Open in current or new tab.
- JSON export and import.
- Local storage as the primary data store.
- Chunked backup through `chrome.storage.sync` when available.
- Support for `chatgpt.com` and legacy `chat.openai.com` URLs.
